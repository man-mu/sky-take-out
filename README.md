本项目是《苍穹外卖》的后端项目，面向管理端和用户端，模拟了外卖平台从接单到完成订单的全流程
  对于管理端，实现了员工权限管理、菜品/套餐上下架、订单流水处理、来单语音提醒，以及营业额、订单等核心数据的图形化报表和Excel导出等实用功能，方便商家高效处理订单
  对于用户端，提供微信一键登录、菜品分类浏览、购物车加删、历史订单查询及催单等功能。但是由于不可抗因素，下单支付时无法调用wx支付接口，所以设置为了点击支付按钮就完成支付
本项目以SSM框架为核心，mapper层采用MySQL储存数据 + redis缓存数据，并整合了JWT（用户鉴权）、WebSocket（实时来单/催单）、Spring Task（定时任务，如超时自动取消订单）、Swagger（接口文档）及阿里云OSS（图片存储）等常用技术

项目附件中包含了完成日志，以及一个简要的新知识的梳理（便于复习）
